# 长期记忆与课程 Wiki · 本地开发计划

在本机实现个人视频资料库、课程 Wiki、跨视频问答、旧对话回忆，以及关页后的任务恢复。**本地验收通过即完成本阶段，可以继续开发其他模块。** 服务器相关工作见[服务器部署计划](./长期记忆与课程Wiki-服务器部署计划.md)，由单独的上线任务启动。

开发时使用 Vite 和绑定到回环地址的 FastAPI。SQLite 数据与本地模型缓存按工作树隔离。开发和验收使用本机环境与现有模型服务。

## 本地运行

沿用现有前后端启动方式。后端使用 Python 3.12 或 3.13，安装 `requirements.txt` 中的依赖。页面统一用「AI」指代模型服务，当前后端通过 `DEEPSEEK_API_KEY` 访问模型服务。

- **AI解析。** 输入链接后依次点「解析视频」和「开始分析」。在同一页查看进度、结果或重试，从「最近解析」找回记录。结果上方点「去问答」，即可带着这条视频的分析和字幕进入对话。视频提供下载格式时，可从预览卡片的「下载视频」展开选项，文件由浏览器下载。
- **B站会话。** 读取 B 站视频信息或开始分析前，页面会先检查当前标签页的会话。首次使用时按提示填入 `SESSDATA`，提交后继续原操作。已有会话时，入口收为「B站会话 · 已填写」，点开可更换或清除。会话保存在当前页面应用的内存中，站内切换可复用，整页刷新或关闭标签页后需要重新填写。
- **AI问答。** 可以按视频、课程或全部资料提问，也可打开已保存的历史对话。桌面宽屏左侧显示分析、右侧显示对话，两侧可分别滚动。手机窄屏可展开或收起分析。课程问答中切换左侧讲次，提问范围仍是当前课程。
- **资料库。** 「视频」用于查找和管理已保存的资料，「课程」用于查看和管理课程。进入课程详情后，可添加和排序各讲、查看课程 Wiki 或进入「课程问答」。

资料库默认保存在 `backend/.study-data/library.sqlite3`，本地 E5 模型保存在同一目录的 `e5-model` 下。进入新的工作树时，可在 `backend/` 准备模型。当前工作树已准备好模型。

```bash
python -m services.study_embeddings --prepare
```

启动后可通过本机 `GET /api/study/status` 查看语义索引状态和待索引条数。模型尚未准备时仍可用全文检索。可用 `STUDY_DATA_DIR` 指定独立的验收数据库目录，并用 `STUDY_MODEL_DIR` 指向已准备的模型，复用权重。

## 资料库与最近解析的管理

| 要做的事 | 操作入口与结果 |
| --- | --- |
| 给已保存的视频改名或分组 | 在「资料库 → 视频」点卡片上的「管理」，填写视频名称或选择分组，再点「保存更改」。可搜索标题、分组或课程，也可用分组下拉框筛选。同一视频可放进一个分组，并可加入多门课程。重新分析同一视频时会保留自定义名称和分组 |
| 新建、改名或删除分组 | 在视频列表上方点「管理分组」。删除分组后，组内视频会移到「未分组」，可继续从资料库查看 |
| 删除已保存的视频 | 在视频卡片的「管理」里点「删除视频」。确认前会显示受影响的课程、Wiki 概念和问答轮次。受影响的旧问答可以保留供查看或一并清除，保留的轮次会退出回忆 |
| 给课程改名或删除课程 | 在「资料库 → 课程」总览点课程卡片上的「管理」。删除课程会移除该课程及其 Wiki，相关旧问答退出回忆，课程中的视频仍可从资料库打开。课程详情的「管理课程视频」用于添加、排序和移出各讲 |
| 删除一条最近解析 | 在「AI解析 → 最近解析」点「管理」，选择要删除的记录并确认。排队或运行中的任务会停止。已归档视频的当前解析和已保存问答可继续从资料库访问。未保存的临时结果及对应的问答入口随记录失效 |

切换首页、AI解析、AI问答和资料库时，顶部菜单栏共用同一套居中宽度和边距。问答页扩展的是正文区域。页面统一预留滚动条空间，长短页面切换时导航位置一致。

## 开发顺序

1. **资料库与课程。** 保存视频标识、分析结果和带时间戳的字幕。公开视频默认保存，可在分析前取消。Panopto 等需要登录的视频由用户主动选择保存，提交前说明 Wiki 整理和问答会向 DeepSeek 发送必要的字幕片段。同一视频按平台标识去重，B 站不同分 P 独立记录。用户创建课程、添加视频并排序，一条视频可以加入多门课。系统提供相关视频建议，由用户确认归属。
2. **后台任务和恢复。** 分析、Wiki 更新和持久问答提交后返回任务 ID。页面可查看状态、重试或取消，关页后任务在后端继续。已选保存的任务把阶段进度写入 SQLite，重启后从可恢复的阶段接上。平台凭证只在执行期间使用，重启后如仍需凭证，提示重新输入。AI 请求的结果未知时，由用户确认是否重试。未选保存的任务和结果保存在内存，完成后可查看 1 小时，服务重启后过期。同一请求 ID 用于防止重复提交。
3. **课程 Wiki。** 视频加入课程后，增量更新已有概念页或新建相关页。概念页展示概念说明、中英文别名、相关页和可点开的字幕出处。后端核对引文的原文、时间和课程归属后发布。更新失败时保留上一版，提供重试。支持改名、补别名、合并重复页和确认跨课链接。
4. **跨视频问答与回忆。** 使用 SQLite FTS5 和本地 `multilingual-e5-small` 检索 Wiki、字幕和相关旧问答，沿用 DeepSeek 组织答案。默认查询当前视频或课程，可主动切到全库。回答标出来源视频和时间，并单独显示参考过的旧问答，用户可关闭回忆。删除视频时更新 Wiki 和索引，受影响的问答退出后续上下文和回忆，可按删除确认框中的选择保留或清除。

## 前后端职责

遵循 [AGENTS.md](../AGENTS.md)。Vue 负责页面和交互，前端 API 模块统一封装请求。FastAPI 路由负责请求校验和响应，后端服务负责后台任务、检索、模型调用与引用核验，存储层负责事务。保留现有即时单视频问答入口。

### 管理接口与存储

资料库请求集中在 `frontend/src/api/study.js`。视频、课程、分组及删除解析记录的界面共用 `StudyManagementDialog.vue`。全站导航宽度由 `NavBar.vue` 和 `main.css` 控制，正文的宽屏布局由 `App.vue` 按当前页面启用。

| 接口 | 用途 |
| --- | --- |
| `GET /api/study/library` | 返回视频、课程与分组。视频条目带有 `group_id`，值为 `null` 表示未分组 |
| `PATCH /api/study/videos/{video_id}` | 提交目标 `group_id`，可同时用 `title` 改名。仅改名时传当前分组，移出分组时传 `null` |
| `POST /api/study/groups`、`PATCH /api/study/groups/{group_id}`、`DELETE /api/study/groups/{group_id}` | 新建、重命名和删除分组 |
| `PATCH /api/study/courses/{course_id}`、`DELETE /api/study/courses/{course_id}` | 重命名和删除课程，由课程总览中的管理入口调用 |
| `DELETE /api/study/analysis/{task_id}` | 删除最近解析里的分析任务记录。`DELETE /api/study/tasks/{task_id}` 用于取消任务并保留记录 |

SQLite 在初始化时补建 `video_groups` 和 `video_preferences`。视频的自定义名称、分组和平台原始信息分开存储。改名时同步更新视频搜索索引，删除分组时由外键把视频的分组置空。删除最近解析由任务服务处理，归档数据在完成分析时已单独写入资料库。
